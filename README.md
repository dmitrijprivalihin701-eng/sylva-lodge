# Sylva Lodge: демо-сайт глэмпинга (Аренда сезон)

Демо-сайт глэмпинга под Екатеринбургом. Сначала делали по мотивам Eywa Lounge (vk.com/eywa_lounge),
потом переименовали в **Sylva Lodge** (sylva — «лес» по-латыни) и заменили все фото на стоковые,
чтобы сайт не повторял эту компанию.

## Файлы
- `site/index.html`: весь сайт (один файл, стили и скрипт внутри)
- `site/img/`: 13 фото с Unsplash (см. ниже)
- `исходники/house-vk-cover.jpg`: старое фото с обложки ВК Eywa Lounge, на сайте больше не используется
- `исходники/запасные фото/`: стоковые фото, которые стояли в треугольниках до трапеции (тоже Unsplash)
- Референсы: `328207eb…jpg` (первый экран), `ИДЕЯ.jpg`, `СТРУКТУРА.jpg`, `ЦВЕТОВАЯ ГАММА.jpg`

## Как открыть
Двойной клик по `site/index.html`, или локальный сервер:
`python -m http.server 8765 --directory site` → http://localhost:8765

## Что на сайте
1. Первый экран на всё окно: фото, шапка поверх фото, огромное SYLVA / LODGE, подписи по углам,
   glass-виджет «Декабрь: выходные разобраны 75%», белые карточки «5,0» и «от 5 000 ₽».
2. «Устали от городской суеты?»: трапеция из трёх треугольников + нумерованное меню 01–07 (по «Структуре»).
   - 01–04 (Лес, Домик, Баня, Чан) никуда не перекидывают: меняют фото в трапеции. Клик по фото открывает его
     на весь экран, там можно листать стрелками (и клавишами ←/→), закрыть по × или Esc.
     Фото и подписи тем — в объекте `TOPICS` в скрипте; файлы `img/topic-*.jpg` можно заменить фото клиента.
   - 05 Цены → блок цены, 06 Бронь → форма бронирования, 07 Локация → карта.
   - В пустом углу слева от трапеции подпись «Фотолокации: каждый угол здесь — готовый кадр для сторис и рилс».
     Текст идёт вдоль косой грани (CSS shape-outside); на экранах уже 1180 px подпись стоит над трапецией.
     Текст держать коротким, иначе не влезет в треугольник.
3. «Настоящий [в сердце соснового леса] уют»: смешанная типографика, карточки Баня / Домик / Чан (по «Идее»).
4. «Домик»: ромбы и преимущества по бокам (по «Структуре»).
5. Цена, 4 шага брони, финал «Пора выдохнуть» с формой, контактами и картой «Как нас найти».
   - Карта OpenStreetMap (бесплатно, без рекламы), затемнена фильтром под стиль сайта.
     Точка-заглушка 56.735, 60.585 (лес под Екатеринбургом): поменять в `iframe` (`bbox`, `marker`)
     и в кнопке «Построить маршрут» (`rtext=~широта,долгота`, ведёт в Яндекс Карты).
     Яндекс-виджет пробовали: в бесплатной версии внизу висит реклама.
- Цвета: почти чёрный фон, медно-оранжевый акцент, стеклянные карточки (по «Цветовой гамме»).
- Прелоадер «Загружаем ваш уют» (одобрен): домик дорисовывается вместе с процентами, загорается окно,
  меняются фразы. Показывается только при первом открытии сайта.
- Клики по ссылкам меню: плавная прокрутка к блоку (0,65–1,4 с, мягкий разгон и торможение).
  Если пользователь сам крутит колесо или тянет пальцем, прокрутка сразу останавливается.
